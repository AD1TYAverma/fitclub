# FitClub Project

This project is a modern and responsive fitness website that helps users stay motivated and achieve their fitness goals. It includes sections like workout categories, features, and membership plans with a clean and engaging design.

It improves user experience by providing a smooth layout, responsive design, and visually appealing interface.

## Features

* Workout Categories
* Clean & Modern UI
* Responsive Design
* Smooth Animations

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Remix Icons (CDN)
* ScrollReveal.js
